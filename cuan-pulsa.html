Cuan Pulsa App

Portfolio / UI/UX Design & Backend Development

Overview

Cuan Pulsa is a mobile application for converting phone credit (pulsa) into cash or other digital payments. I joined the team as a freelance contributor, handling both the UI/UX design and backend API development. The app required an intuitive mobile interface and a secure, reliable backend to handle financial transactions.

My Role

As UI/UX Designer & Backend Developer, my responsibilities included:

  • Designing mobile app UI/UX using Figma — intuitive, responsive, and brand-aligned
  • Creating user flows, wireframes, and final production-ready designs
  • Developing RESTful API using Laravel for pulsa conversion, authentication, and transaction logic
  • Integrating the API with third-party payment systems
  • Collaborating with the mobile developer team to synchronize design and backend functionality
  • Conducting testing and debugging to maintain system performance and security
  • Building a responsive company profile website and landing page using Laravel
Tech Stack

Figma Laravel RESTful API PHP Payment Gateway Integration MySQL

Challenge & Solution

The biggest challenge was ensuring secure and accurate transaction handling for financial data, while also delivering a UI that felt simple and trustworthy for end users. On the design side, the focus was on reducing friction in the conversion flow. On the backend, proper API authentication and transaction validation were prioritized to prevent data inconsistencies and security vulnerabilities.
