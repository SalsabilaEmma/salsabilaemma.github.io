mbaktutik.com

Portfolio / Online Ticketing Platform

Overview

mbaktutik.com is a live online ticketing platform developed for PT. Gita Nada Harmonia, Madiun. The platform enables event organizers to sell tickets online, manage events, monitor sales in real-time, and handle fund withdrawals. I was responsible for both technical development and business operations of the platform.

My Role

As Full-Stack Developer & Business Operations Lead, my responsibilities included:

  • Developing and maintaining the full platform — frontend and backend
  • System performance optimization and debugging
  • Handling technical documentation and new feature releases
  • Bridging communication between development and marketing teams
  • Managing client negotiations, presentations, and MoU signing
  • Monitoring real-time ticket sales and ensuring accurate transaction records
  • Managing cashflow reports including income/expense summaries and fund withdrawals
Tech Stack

Laravel PostgreSQL RESTful API PHP HTML / CSS Bootstrap JavaScript

Challenge & Solution

One of the main challenges was handling concurrent ticket purchases during high-demand events while keeping transaction data accurate. This was addressed through proper database transaction management and queue handling in Laravel. Additionally, managing both technical and operational responsibilities simultaneously required strong cross-functional coordination between development, marketing, and client-facing teams.
